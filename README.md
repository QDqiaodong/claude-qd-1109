# 养蜂场 · 蜂箱台账与采蜜批次

养蜂场业务管理：蜂箱台账、蜂箱巡检（月历视图，按蜂箱+日期唯一，含健康判定与复检）、采蜜批次（蜂蜜批次质检放行、隔离整改、复检与入库流转）、客户管理。

## 技术栈
- 后端：Spring Boot 3.3 + Spring Data JPA + MySQL
- 前端：Vue 3 + Element Plus + Vite

## 启停
```bash
sh start.sh     # 启动（docker compose 拉起 mysql + backend + frontend）
sh stop.sh      # 停止
```

## 蜂蜜批次质检放行流转

批次状态机：

```
待质检 ──初检合格(含水率≤20% 且感官合格)──▶ 已放行 ──入库──▶ 已入库
  │
  └──初检任一项不合格──▶ 隔离待整改 ──登记整改说明 + 复检合格──▶ 已放行
                              │
                              └──复检仍不合格──▶ 隔离拒收（终态，明确拒绝入库）
已作废：终态
```

规则要点：
- 每个批次形成可回溯质检记录：抽样编号（全局唯一，不可跨批次复用）、含水率、感官结论、检测人、检测时间、检测说明；轮次分初检 / 复检。
- 同一批次至多一条生效中质检记录（DB 唯一索引 + 行锁保证），复检后旧初检记录转为历史记录保留可查。
- 含水率 > 20% 或感官不合格任一不满足即隔离；隔离批次须先登记整改说明才能复检，复检最多一次，仍不合格则隔离拒收。
- 仅「已放行」批次可入库；质检 / 整改 / 复检 / 入库均在批次行锁内校验当前状态，
  两人同时提交或重复点击只有一笔生效，旧页面无法把已放行 / 已入库批次覆盖回退。
- 列表支持按批次状态、质检结论（未质检 / 初检合格 / 初检不合格 / 复检合格 / 复检不合格）筛选；
  不可执行的动作在页面上禁用并以 tooltip 说明原因；「质检回溯」可查看该批次全部质检与整改历史。
