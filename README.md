# 养蜂场 · 蜂箱台账与采蜜批次

养蜂场业务管理：蜂箱台账、蜂箱巡检（月历视图，按蜂箱+日期唯一，含健康判定与复检）、采蜜批次、蜂蜜批次质检放行（初检、隔离整改、唯一复检、拒绝入库与入库联动）、客户管理。

## 技术栈
- 后端：Spring Boot 3.3 + Spring Data JPA + MySQL
- 前端：Vue 3 + Element Plus + Vite

## 启停
```bash
sh start.sh     # 启动（docker compose 拉起 mysql + backend + frontend）
sh stop.sh      # 停止
```

## 蜂蜜批次质检放行
- 质检记录包含抽样编号、含水率、感官结论、检测人、检测时间、说明及初检/复检轮次。
- 抽样编号全库唯一；同一批次仅允许一条生效中的质检记录，复检后旧记录保留为历史。
- 含水率 ≤ 20% 且感官合格时放行；任一不合格即进入「隔离待整改」。
- 隔离批次必须先登记整改说明，整改后最多复检一次；复检仍不合格进入「隔离拒收」并禁止入库。
- 只有「质检放行」或「复检合格」批次可通过原入库动作进入「已入库」。
